Or use lattice anonymously

No node? You can use lattice anonymously. You can browse pages and comment on them, but you can't host pages without a node.

What this uses and keeps

lattice makes a private reader identity on this computer the first time, and your comments are signed with it: the people you comment to see its name as the author. The network: HTTPS to roller.urbit.org and bootstrap.urbit.org (to make the reader identity and look up keys), and UDP to the Urbit network and the ships you read. A network that blocks UDP cannot read. lattice gets the reader ready while this page is open, and reads the start list. What it keeps, on this computer only: the reader identity, the network state, and the pages you read recently. A comment goes to the page's publisher and is not kept here. Connecting a node before you use lattice anonymously deletes the identity. Hosting pages, bookmarking and following need a node of your own.

Ship software

    %mcp is not installed on this ship.

    lattice installs the rest through %mcp, so it has to go on first — and it cannot install itself. From your ship's dojo:

    |install ~nisfeb %mcp

    Then press check again.

    %grubbery is missing. lattice runs as a nexus inside it, so it is installed first, over Ames from a publishing ship.

    This takes a few minutes — the whole desk transfers over Ames.
