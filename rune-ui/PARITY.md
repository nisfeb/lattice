# Parity ledger

What the web client (`ui-src/`) and the Tauri desktop app (`desktop/`) do, and whether this client does it. One line per feature. The loop in `../rune-parity-loop.md` works down this list and edits it.

Marks: `[x]` done and checked, `[ ]` not built, `[~]` built in part (the line says what is missing), `[!]` blocked (the line says by what).

"Checked" means a unit test, plus a headless scripted run of the real screens, plus a live test against a fresh fake ship when the feature talks to the ship. The owner ran one build in a real window on 2026-11-17 (see the last section). Features built after that have not been seen in one.

- [x] Spreadsheet (flat ODS): grid with sheet tabs, and typing text, a number, true or false into a cell. - [x] Spreadsheet: formulas worked out, so a sheet with formulas can be changed and a typed formula is written. - [x] Spreadsheet: numbers shown by the cell's number format. Checked by a LibreOffice-made sheet typed into by this client and by the web client's engine under node: the two pages are the same bytes, kept as a test. Bold, italic, underline, struck through, the text's colour, the cell's background and its alignment, from the cell's style with its parents and the default style folded in, as the web client reads them.
